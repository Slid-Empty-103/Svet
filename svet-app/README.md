# Свет — журнал отключений света (Android 8+, проверено в расчёте на Android 11)

## Что умеет

- **Журнал**: кнопки «Света нет» / «Свет есть» пишут время. Долгое нажатие на кнопку — отметить с другим временем. Нажатие на запись — изменить время, поменять тип или удалить.
- **Прогноз**
  - пока свет есть: «Свет могут отключить через 5–20 мин (вероятность за 3 часа ≈ 45%)» — по дню недели и времени суток прошлых отключений, свежие записи весят больше;
  - пока света нет: «Скорее всего включат через 20–50 мин» — по длительности прошлых отключений.
  - Нужно хотя бы 3 записи «света нет» (и 2 завершённых отключения для прогноза включения). Чем больше данных — тем точнее.
- **⏰ Ждать свет** (будильник): нажимаешь перед сном, пока света нет. Приложение следит за Wi‑Fi; когда телефон подключился, оно проверяет, что **реально открывается Википедия** (страница «Земля») через эту Wi‑Fi сеть, и только тогда звонит будильником + пишет в журнал «свет есть».
  - В журнал время пишется как *время подключения к Wi‑Fi минус поправка на загрузку роутера* (⚙ → «Поправка», по умолчанию 60 с). В заметке к записи видно: когда появился Wi‑Fi, когда — интернет.
  - Если телефон на момент старта уже был на Wi‑Fi, приложение ждёт, пока Wi‑Fi пропадёт и вернётся.
  - Опционально (⚙): подключение зарядки тоже считается сигналом «свет дали».
- **⬛ Чёрный экран**: чистый #000000 на весь экран (на AMOLED пиксели выключены). Запусти видео на YouTube → сверни в мини‑окно (картинка в картинке) → открой «Свет» → «Чёрный экран». Выход: долгое нажатие или «Назад».

## Как получить APK

### Вариант 1 — Android Studio
1. Установи Android Studio, открой папку проекта (File → Open).
2. Дождись синхронизации Gradle.
3. Build → Build APK(s). Файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. Скопируй на телефон и установи (разреши установку из неизвестных источников).

### Вариант 2 — без Android Studio (GitHub Actions)
1. Создай репозиторий на GitHub и залей туда содержимое этой папки (вместе с `.github`).
2. Вкладка Actions → Build APK → Run workflow.
3. Когда сборка закончится, скачай артефакт `svet-apk`.

## Важно для режима «Ждать свет»
- При первом запуске приложение попросит убрать ограничения батареи — разреши, иначе ночью Android может усыпить приложение.
- Если роутер питается от генератора, Wi‑Fi не пропадёт и сигнал не сработает: в этом случае используй вариант с зарядкой или отключай роутер от генератора.
- На некоторых оболочках (Xiaomi, Huawei, Samsung и др.) стоит дополнительно разрешить автозапуск / «без ограничений» в настройках приложения.
